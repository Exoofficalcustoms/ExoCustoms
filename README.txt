EXO WEBSITE — IMAGE SETUP
=========================

The website expects these image files in the same folder as index.html:

  wheeliebar.jpg  — already downloaded automatically ✓
  brakes.png      — SAVE the brakes image yourself
  plate.png       — SAVE the guts plate image yourself

HOW TO SAVE THEM:
  1. Right-click the brakes photo → Save As → name it  brakes.png
     Save it to:  C:\Users\BLACK PC\Desktop\exo website\
  2. Do the same for the plate photo → name it  plate.png
     Save it to:  C:\Users\BLACK PC\Desktop\exo website\

Once both files are there, open index.html in your browser — all images will show.

PAYPAL SETUP:
  Open app.js and on line 5 replace  your-paypal@email.com  with your real PayPal email.
